This is an orchestrated project thatI followed along with in order to gain more familiarity with JS. In this project, I created a functioning Amazon webpage filled with items that the user can put into their cart. The user may select a quantity before adding, and can then check into their cart by clicking on the cart icon. From there, the user may see how much the order will cost from the checkout the page. Additionally, the user may select a shipping option, place the order, and track the order. In order to make this fully functioning, I utilized a backend by making calls to it, I created organized code that contains methods like modules, inheritance, classes, and promises, and I made use of the DOM, local storage, and several other relevant components. Additionally, I implemented test cases using jasmine to make sure that the webpages would function as intended.
